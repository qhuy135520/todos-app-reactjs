# Todos App

A simple Todo application built with React and Vite. This project allows users to create, read, update, and delete tasks efficiently.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Responsive design

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Vite**: A fast build tool and development server for modern web projects.
- **CSS**: For styling the application.

Usage
To add a new task, type the task name in the input field and click the "Add" button.
To mark a task as completed, click on the checkbox next to the task.
To edit a task, click on the task name, make your changes, and press Enter.
To delete a task, click the "Delete" button next to the task.
